# Code of Conduct

This workshop and repository exist to help people make their first open-source contribution. That only works in a space where everyone feels safe asking questions and making mistakes.

## Expected behavior

- Be respectful and patient — especially with people asking "beginner" questions. Everyone here was new to Git once.
- Give feedback on code and ideas, not people.
- Assume good intent, and extend the same when giving feedback on someone else's PR.
- Help others when you can; ask for help when you need it.

## Unacceptable behavior

- Harassment, discriminatory jokes or language, or personal attacks, in this repository or during the workshop.
- Dismissive or discouraging responses to beginner questions.
- Publishing others' private information without consent.

## Scope

This applies to all interactions in this repository (issues, PRs, commit messages, review comments) and during the live workshop.

## Reporting

If something happens that makes you uncomfortable, tell a facilitator directly, or email the workshop organizers. Reports are handled promptly and confidentially.

## Enforcement

Facilitators may remove comments, close PRs, or ask someone to leave the workshop if this Code of Conduct is violated. The goal is always to keep this a safe space to learn — not to punish honest mistakes.
