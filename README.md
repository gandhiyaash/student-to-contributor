# Student → Contributor 🚀

**Build with AI. Understand your code. Use Git. Contribute to open source.**

```text
AI
 ↓
Code
 ↓
Git
 ↓
GitHub
 ↓
Issue
 ↓
Branch
 ↓
Pull Request
 ↓
CI
 ↓
Review
 ↓
Merge
```

This repository is a tiny, real browser game (**Coin Catcher** — not a real wallet, no real Bitcoin involved, and it currently ships *broken*) that you'll use to go through a complete open-source contribution: from an issue, to code, through Git, onto GitHub, into a Pull Request, past CI, through review, to merge.

**Your mission: open your first Pull Request.**

## Before the workshop

Read [`SETUP.md`](SETUP.md) and complete it — Git installed, GitHub account ready. Takes about 10 minutes.

## During the workshop

Your facilitator runs the session from [`WORKSHOP.md`](WORKSHOP.md). You'll follow along and contribute using:

- [`tasks/beginner.md`](tasks/beginner.md) — never used Git before? Start here.
- [`tasks/intermediate.md`](tasks/intermediate.md) — comfortable with the basics, want to touch the app or docs.
- [`tasks/advanced.md`](tasks/advanced.md) — ready to dig into validation, tests, accessibility, or a real bug.

Contributing itself: [`CONTRIBUTING.md`](CONTRIBUTING.md).

## Learn more, any time

- [`docs/bitcoin.md`](docs/bitcoin.md) — Bitcoin in about 5 minutes.
- [`docs/ai-assisted-development.md`](docs/ai-assisted-development.md) — how to actually use AI in a real codebase.
- [`docs/git-walkthrough.md`](docs/git-walkthrough.md) and [`docs/git-vs-github.md`](docs/git-vs-github.md) — Git and GitHub, taught through this project.
- [`docs/open-source.md`](docs/open-source.md) — what open source actually means.

No internet at the venue? [`OFFLINE.md`](OFFLINE.md) has you covered — everything still works.

No Claude Code / AI access? Not required. Every task above is fully completable without it.
